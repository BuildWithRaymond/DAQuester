# DAQuester 1.0.5

Automated travel now closes Undine's weapon warning, removes the equipped weapon
and waits for server confirmation before continuing. A full inventory or an
unanswered removal pauses with instructions. Suomi's roleplay entry notice closes
before fast-walk recovery, including when the popup rejects a pending step.

Ordinary Spare a Stick rewards now complete the current attempt and save its
eight-hour next-attempt deadline, whether Repeat is checked or not.

- A manual pause retains observed Callough completion evidence. Later reward
  packets can finish confirmation while automation remains paused, with no
  movement, additional dialog command or repeated submission.
- Completion uses the observed server reply time. Validated Callough replies,
  six branches consumed and experience gained remain required; unrelated or
  stale evidence leaves the transaction pending.
- The journal shows **Completed for now** and the next date even while offline.
  Confirmed permanent completion still disables repeats.

Verified with synthetic interruption, late-packet, restart, generation-isolation,
reward-ordering and ownership regressions, plus the full suite and native dark
UI checks. No real characters are operated during verification.

Check for updates in Settings. Download and installation remain separate choices;
finish quests and close DAQuester-launched game clients before installing. Saved
Data remains outside the package. SHA-256 checksums accompany the unsigned files.
