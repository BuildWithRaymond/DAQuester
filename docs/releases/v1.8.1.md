# DAQuester 1.8.1 — One-click updates

Click **Update and restart** once in Settings. DAQuester checks for a newer
version, downloads it, waits for active work and game clients to finish, saves
progress, then installs and relaunches automatically.

Startup checks remain optional and off by default. Checking alone does not
download or install. Download or handoff failures leave the app open; retry with
another Update click. A package left from an earlier run still needs a fresh click.

Versions before 1.8.1 use their existing update controls to install this version.
The single-click flow is available after that upgrade. Optional AislingExchange
supply dispatch remains gated pending its separate qualification.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
the runtime and pinned DAWindower X. Saved Data remains outside the package.

See the [setup guide](https://github.com/BuildWithRaymond/DAQuester/blob/v1.8.1/docs/GETTING_STARTED.md).
