# DAQuester 1.7.2 — Altar Worship resume recovery

Altar Worship now remembers class and reward eligibility for the saved journey.
Once established, reconnecting or resuming later offerings does not require
another class check. This fixes a saved queue pausing with
"Fresh class and acknowledgement of the Altar reward are required before dispatch."

Existing confirmed offerings and accepted reward notices also establish prior
eligibility. Your offering count and next offering time stay saved. A new journey
still checks the class and requires reward consent when the class does not earn
the legend mark. The final reward still requires fresh observed evidence.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
the runtime and pinned DAWindower X. Saved Data remains outside the package.
Update checks, downloads and installation remain separate player actions.

See the [setup guide](https://github.com/BuildWithRaymond/DAQuester/blob/v1.7.2/docs/GETTING_STARTED.md)
and [quest details](https://github.com/BuildWithRaymond/DAQuester/blob/v1.7.2/docs/QUESTS.md).
