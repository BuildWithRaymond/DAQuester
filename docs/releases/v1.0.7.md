# DAQuester 1.0.7 — Quest endings and smoother travel

This update fixes the last part of Spare a Stick and Perfect Hairstyle: dismiss
the reward message, save the verified outcome and move on to the next queued
quest. If popup cleanup stops, Resume finishes it without submitting the quest
again. Unfamiliar pages stay open for review.

Hairstyle ring rewards still count as a weekly attempt. The quest's legend goal
finishes only when your own **Loved by Suomi Mundanes** mark is verified. Eeva's
“Thanks again” reply now explains that you've already helped her, instead of
trying to choose Ponytail from a finished conversation.

Keane now follows **Suomi Help → Please escort me out of suomi → Next**. The
buttons come from the live menu, and travel continues from the actual landing.

Fast walking no longer pauses and restarts route planning for every monster
update. Monsters in the way still get avoided, occupied exits trigger a new
route, and nearby players still slow the pace.

**Shinewood Faerie now requires level 11+** to pass Forest 7. This also applies
to saved characters when they're offline.

Update through **Settings → Check for updates**, then download and install when
your quests and game clients are safely stopped. Your saved characters,
encrypted passwords, queues and quest journals stay in place.

All **689 tests**, native UI checks and release package verification pass. These
checks use synthetic sessions; live validation of this patch is still pending.

Coming from an older version? The [1.0.6 announcement](https://github.com/BuildWithRaymond/DAQuester/releases/tag/v1.0.6)
covers the new planner, character launches, queues and remembered legend marks.
