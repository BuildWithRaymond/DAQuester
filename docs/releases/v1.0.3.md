# DAQuester 1.0.3

Faster automated quest travel, shorter routes and a polished native dark interface.

- Fast mode is an optional checkbox saved per character. Quest walking uses
  Excalibur's 160 ms pace when alone and returns to 430 ms around nearby players.
  Immediate movement presentation and a bounded step queue keep fast travel
  responsive; confirmed positions and recovery still come from the server.
- Travel compares known doors, arrival tiles, world-map landings and directed
  shortcuts by collision-safe walking distance. It replans around live blockers
  and avoids unnecessary NPC approach steps.
- Fix stale button corners, text escaping partial repaints and shortened action
  labels. Size quest action columns from their measured labels, including on
  small screens. Shared native WinForms controls use Fluent 2 foundations for
  consistent states, focus, spacing and interface typography.

Validated with 385 automated tests, focused movement/quest/update tests, native
UI checks, and installer/portable/update package verification. UI checks cover
keyboard actions, repeated repaints, compact windows and scaled control geometry.
No live fast-mode journey or physical mixed-DPI monitor run is claimed.

Download `DAQuester-win-Setup.exe` or `DAQuester-win-Portable.zip`, or check for
updates in Settings. Startup checks are optional; download and installation are
separate actions. Finish quests and close game clients before applying an update.

Both packages include .NET and support DATester 7.41. Saved journals and settings
stay in `%LOCALAPPDATA%\DAQuester\Data`. Packages are unsigned; SHA-256 checksums
and the stable updater feed accompany this release.
