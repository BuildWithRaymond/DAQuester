# DAQuester 1.6.0 — Tray scheduling and research recovery

The public release keeps the pinned **DAWindower X**, including its managed
caption **+** action. Your saved characters still launch through DAQuester;
the + action opens a blank login. The separate standard-edition comparison build
is not the public package.

Closing the window now keeps DAQuester in the **system tray** by default, so
scheduled work can continue. Click its icon to reopen the window, or use the tray
menu to check scheduler status, pause scheduling, or exit. Settings can disable
tray mode and optionally start DAQuester when you sign in to Windows. Sign-in
startup defaults off and does not enable schedules. Keep Windows signed in and
the PC awake; this is a desktop tray app, with no signed-out execution.

**Scheduler recovery** now starts a new due repeat when an old resume flag still
refers to an already-completed attempt. Saved submissions, reward cleanup,
permanent goals and verified cooldowns retain their recovery rules. Scheduler
closes only the game clients it opened when work ends. Already-open clients are
left alone; an entry blocked for that reason needs explicit Resume after the
client is closed.

**Wizardy research** handles the captured login-tile menu interruption, leaves
research tiles before supplies, and verifies the observed Sorcery result and
completed carried batches. The exact observed failed experiment retains its
parchment: it is recorded without a reward and can continue using that same
scroll. Uncertain purchases and submissions remain saved and are not resent.
Live verification reached four further failed experiments, followed by the
server's 12-hour rest and verified popup cleanup. Automatic purchase and
successful Song results are also observed. Assistant work, Song banking and
unrecognized outcome variants retain their qualification limits.

The captured **Red Moon event popup** is closed at guarded quest and travel
boundaries using its current server page. Unfamiliar events remain available for
review. The captured popup handling has synthetic coverage; a live event-close
receipt is still unverified.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
the .NET runtime, setup instructions and these notes. No separate runtime install
is needed by players. Keep all portable files together. Saved Data remains
outside the package. Update checks default off; checking, downloading and
installing stay separate player actions, with the existing safe-exit checks.
