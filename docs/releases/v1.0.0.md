# DAQuester 1.0.0

The first public DAQuester release brings four observed quest recipes into a
fully dark midnight journal, with searchable legend quests and optional
Developer mode.

Download `DAQuester-win-Setup.exe` or extract `DAQuester-win-Portable.zip`.
Both include .NET. Supports the exact DATester 7.41 executable; no game files are
included. See [Getting started](https://github.com/BuildWithRaymond/DAQuester/blob/v1.0.0/docs/GETTING_STARTED.md).

Optional startup checks are off by default. Download and installation are
separate actions in Settings. Finish quests and close game clients before
installing. Data is stored in `%LOCALAPPDATA%\DAQuester\Data`; read the migration
instructions before moving from an older folder build.

Packages are unsigned. SHA-256 sums and update metadata accompany this release.
The full test suite, native dark UI smoke and package verification must pass
before publication. Current quest-specific limits remain documented in the repo.
