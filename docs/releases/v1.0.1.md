# DAQuester 1.0.1

This packaging correction includes the complete Velopack MIT notice and licenses
and third-party notices from the exact .NET core and desktop runtimes shipped
with the app. Package verification now requires these files.

Quest, interface and optional update behavior is unchanged from 1.0.0.
Download `DAQuester-win-Setup.exe` or `DAQuester-win-Portable.zip`, or use Settings
in 1.0.0 to check, download and install this release after closing game clients.

Both packages include .NET and support the exact DATester 7.41 client. Data stays
in `%LOCALAPPDATA%\DAQuester\Data`. Downloads are unsigned; checksums and the update
feed accompany this release.
