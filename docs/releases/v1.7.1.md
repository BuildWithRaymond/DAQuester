# DAQuester 1.7.1 — Research setup recovery

Wizardy research now recovers when the server closes a setup menu or the
connection changes before an experiment is submitted. A saved Begin, Specific,
Sorcery, Assistant or informational Next checkpoint can restart from fresh
dialogue. It preserves earlier results and does not claim an attempt, reward,
completion or cooldown. This fixes the reported `Research submission belongs
to an earlier connection` blocker for a harmless setup menu.

Actual experiment submissions, payments, deposits and potion doses still need
their matching receipts. Unknown popups and conflicting result cleanup remain
available for review instead of resubmitting uncertain transactions.

Exkuranum supplies now follow the requested **use the last potion, then restock**
rule. Research continues with any positive carried count. At zero it refills to
**30**, using the existing verified shop purchase and safe return. Potions in
multiple bag stacks count together. The health check still requires consumption
and actual full HP before another experiment; saved purchases reconcile before
another payment. A full corrected automatic live run remains unqualified.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
the runtime and pinned DAWindower X. Saved Data remains outside the package.
Update checks, downloads and installation remain separate player actions.

See the [setup guide](https://github.com/BuildWithRaymond/DAQuester/blob/v1.7.1/docs/GETTING_STARTED.md)
and [quest details](https://github.com/BuildWithRaymond/DAQuester/blob/v1.7.1/docs/QUESTS.md).
