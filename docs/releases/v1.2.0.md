# DAQuester 1.2.0 — Quest planner and original character portraits

The current journey and character queue now share one full-width card. Compact
queue rows leave more room for quests, and the taller library fills the rest of
the planner. The separate NPC conversation panel and saved home-location controls
are removed. Existing saved data still loads through legacy migration.

Individual quest actions stay together at the bottom. Compact windows show
centered icons with tooltips; wide windows keep their labels. The single-quest
scroll/play icon differs from the queue's list icon. Add to queue inserts the
displayed quest once for its character. Resume requires saved progress or an
unconfirmed submission; Pause and Stop require an active operation. A paused queue
retains its own Stop action. Recipe step counts and the gold activity trail show
progress without inventing checkpoint completion.

Characters use original artwork read from the installed client's DAT files,
matching observed outfit, direction and actions. The current journey includes a
faint 5.5× nearest-neighbor accent. Circular portraits appear in the chooser,
Characters page and Run history; face-zero outfits include their original head
skin. Each character's observed outfit is saved by server profile across logout
and restart. Saved artwork is presentation only. Client packets do not expose
the exact native animation frame, so action timing is reconstructed. Game files
and replacement artwork are not bundled.

The interface uses Lucide icons, equal-width navigation, matching Launch and
chooser heights, and permanently outlined controls. Project-owned code is easier
to browse: view models and queue persistence/execution have separate files,
dense statements are expanded, and contributor documentation maps each feature
to its implementation. Upstream sprite decoders retain their license notices.

This release also includes all incoming changes through PRs #8 and #9:

- Emerald Dawn lists each recipient's legend marks, gold and experience range.
  Knights, Necromancer and Rogue outcomes retain the incoming live validation.
  Gans is no longer offered, and choices can change until the handover.
- Berg's full story requires a saved receipt; an existing recovery mark alone
  does not skip it. Skan's sale requires the observed server sale message,
  rather than a gold difference, and respects connection-generation boundaries.
- Server messages remain in replays and diagnostics; player chat is excluded.
- Tolerant world-map travel can choose a nearby free tile when the target is a
  prop. History uses Completed consistently, and the choice-checkpoint AppTest
  passes the new change argument.

The four quest policies, observed-evidence boundaries, connection isolation,
durable checkpoints and reconciliation remain protected. Updates default off;
checking, downloading and installing remain separate actions. User Data stays
outside packages. Tests use synthetic state and never operate real characters.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**; both include
the runtime. Keep the complete portable folder together. See
[character preview](https://github.com/BuildWithRaymond/DAQuester/blob/v1.2.0/docs/character-preview.md)
for artwork and animation limits, and
[validation](https://github.com/BuildWithRaymond/DAQuester/blob/v1.2.0/docs/validation.md)
for release verification results.
