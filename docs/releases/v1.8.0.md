# DAQuester 1.8.0 — Bag sorting and daily check-ins

**Sort Bag** and **Sort All Bags** are compact, ordinary-click actions. They use
DAOrganizer's category ordering, quick-use slots and trinket layout. Busy and
offline characters are skipped; uncertain moves stop without automatic retry.

**Avid Temuairian Daydreamer** visits Celesta for one daily check-in and saves the
server's actual consecutive-login count. Optional scheduling and continuation
preserve pending submissions and the first verified 30-day goal. Registration
now survives the login-server redirect, fixing the wait for confirmation after
a registered character has logged in. A full 30-day automatic journey remains
unqualified live.

This version also includes optional AislingExchange parcel pairing, collection
reports and return checkpoints. **Production supply dispatch remains disabled**
until worker certification and live parcel qualification finish. Received quest
supplies stay in the character's bag. Supported sends record actual item-specific
postage; unknown fees alone do not block a send.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
the runtime and pinned DAWindower X. Saved Data remains outside the package.
Update checks, downloads and installation remain separate player actions.

See the [setup guide](https://github.com/BuildWithRaymond/DAQuester/blob/v1.8.0/docs/GETTING_STARTED.md)
and [quest details](https://github.com/BuildWithRaymond/DAQuester/blob/v1.8.0/docs/QUESTS.md).
