# DAQuester 1.0.4

Repeatable quest controls, main-window pages and a complete account manager.

- Spare a Stick offers **Run again** after a completed single attempt. **Repeat**
  schedules further attempts with the eight-hour cooldown. Confirmed permanent
  Callough completion still stops repeats, and ambiguous transactions stay saved
  for reconciliation. Other quest policies stay intact.
- Quest buttons follow actual execution, so old saved Running/Scheduled state
  cannot leave them locked after an action finishes.
- Left navigation switches pages inside the main window. Quest progress and
  library filters stay in place, and opening Settings keeps quests running.
  Keyboard focus scrolls quest actions into view on small screens.
- Account manager shows every name and masked password in one editable table.
  Add/remove accounts, edit multiple rows, then Save accounts. Names update the
  journal immediately. Blank passwords keep saved credentials; renaming retains
  the password. Passwords remain encrypted for the current Windows account.
- New profiles start with an empty character list. Account manager handles
  character editing; Settings handles the game client and application updates.

Verified with 392 automated tests, synthetic quest regressions, native
UI checks at standard and compact sizes, bulk account edits, and isolated Windows
password encryption checks. No real character actions are used in verification.

Check for updates in Settings, or download `DAQuester-win-Setup.exe` or
`DAQuester-win-Portable.zip`. Download and installation remain separate choices.
Finish quests and close game clients before installing. Saved user Data remains
outside the package. Packages are unsigned; SHA-256 sums accompany the release.
