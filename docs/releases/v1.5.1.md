# DAQuester 1.5.1 — Auto Tasks and character legends

**Auto Tasks** gives repeatable activities their own page, with search, category
and status filters, details and controls for the selected character. **Wizardy
research** supports researching alone or with an eligible owned wizard assistant.
It buys one Parchment Scroll at a time, checks item and gold receipts, recognizes
the observed research result, and preserves interrupted submissions for recovery.
Song banking requires its own acceptance receipt. Unknown replies pause for
review. Automatic scheduling stays off until explicitly enabled.

**Altar Worship** appears in Tasks for every class. Its quest entry is retained for
Priest, Bard and MasterPriest characters, with the different reward expectations
explained before starting. Existing offering progress and schedules are retained.

Open a character's **legend marks** to read complete mark text and dates with the
original game icons. Remembered marks remain available offline; they do not
replace fresh evidence when running a quest. Game artwork is read from your
supported installation and is not bundled.

Desktop Danaan starts use the fixed Cail route and supplied-Mold rite acceptance.
Recovery also recognizes the specifically observed carried Rotten Apple receipt.
Unknown branches and uncertain handoffs remain paused. Faerie return journeys
finish at the verified safe forest destination or a confirmed escape rather than
continuing unnecessarily toward Mileth.

This release also includes **Awakening**, **Peasant's First Steps** and **Crypt
Climb**, a shared Terror of the Alley and Garden journey, the hunting engine,
health/stat/gear observations and the optional saved-character scheduler. Quest
preparation, journey planning and recovery have been expanded, alongside the
observed Fisk and Danaan journeys. Managed DAWindower X launches include an
owned-client **+** window action. Code organization and regression coverage have
been expanded. The native dependency build now loads the correct PowerShell
utility module when invoked from another host.

Research has one observed successful status-only result and synthetic recovery
and continuation coverage. Its full repeated journey and Song banking still need
live verification. Danaan Band and the full ten-offering Altar journey retain the
qualification limits documented in the quest guide. Synthetic checks never
operate real characters.

Download **DAQuester-win-Setup.exe** or **DAQuester-win-Portable.zip**. Both include
.NET, setup instructions and these notes. Keep the complete portable folder
together. Saved Data stays outside the package. Checking for updates, downloading
and installing remain separate player actions; update checks default off.

See the [setup guide](https://github.com/BuildWithRaymond/DAQuester/blob/v1.5.1/docs/GETTING_STARTED.md)
and [quest details](https://github.com/BuildWithRaymond/DAQuester/blob/v1.5.1/docs/QUESTS.md).
