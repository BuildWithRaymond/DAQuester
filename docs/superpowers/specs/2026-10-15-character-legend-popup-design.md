# Character legend popup

The Characters page exposes a Legend marks button beside Remove within each
saved character's expanded details. It opens that character's marks without
changing the selected character. The expanded editor no longer includes inline chips.

The popup keeps DAQuester's existing dark surfaces, text, gold accent, typography
and window chrome. Its body follows the supplied game reference: a compact,
scrolling vertical list with an aligned icon column and complete mark text and
dates in server order. Long marks wrap instead of truncating. The window resizes,
has a Close button, and supports Escape and keyboard focus.

Own self-look packets retain the actual icon alongside each existing legend text.
Character memory saves these presentation entries through the same own-identity,
fresh-revision and generation guards. Existing text-only memory remains readable
and uses a neutral fallback symbol; no icon is guessed from mark wording. Quest
evidence continues to use the existing text array. Server text colors do not
replace the application's palette. A server mark with no icon keeps the aligned
blank column.

Current observed marks take precedence over remembered marks. Known empty,
unobserved and offline states remain distinct. Popup bindings follow the clicked
character and update with its existing view model. Synthetic native captures
cover normal, narrow, scrolling, remembered and empty states; focused tests and
both full xUnit projects verify metadata and memory behavior. No live characters
or Excalibur working copies are operated.
